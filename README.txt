Сайт ALPHA 3 со стикерами и музыкальным плейлистом.

Для GitHub Pages загрузите index.html, папку stickers и папку music целиком в корень репозитория.
В папке music находятся три аудиодорожки; они автоматически проигрываются по очереди и затем повторяются.
Не переименовывайте папки stickers и music: пути к файлам уже прописаны в HTML.
